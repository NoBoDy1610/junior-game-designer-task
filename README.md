# Junior Game Designer – Recruitment Task

A recruitment assignment consisting of two parts: a responsive webpage built with HTML and CSS, and a room renovation plan.

## Part 1 – Responsive Webpage

A webpage recreating the provided reference designs using only HTML and CSS.

### Features
- Three responsive layouts:
  - Mobile: below 583px
  - Tablet: 583px–900px
  - Desktop: above 900px
- Geometric shapes created entirely with CSS
- Smooth transitions between responsive layouts
- Hover animations for individual elements
- Automatic scaling to fit smaller viewport heights
- Reduced-motion accessibility support
- No JavaScript, CSS frameworks or image assets

### Technologies
- HTML5
- CSS3

### How to Run
1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Resize the browser window to see the responsive layouts and animations.

## Part 2 – Room Renovation Plan

The `plan.txt` file contains a step-by-step room renovation plan written in English, within the 1,000-character limit.
